# DSH Plugin Builder

DSH Plugin Builder is a planned Agent preset and workflow for turning a developer's business requirement into a tested, installable, and traceable DSH plugin.

The project combines:

- Superpowers-style software-engineering discipline;
- DSH-specific plugin architecture knowledge;
- deterministic scaffolding and validation tools;
- a resumable workflow with explicit design, installation, and publishing gates.

The repository currently contains the approved design checkpoint. Implementation has not started yet.

See [the design](docs/plugin-builder-design.md).
